# ChesStats ♟️

## Synopsis

**ChesStats** is an Android application that consumes the **Chess.com public API** to display simple chess statistics, player profiles, rankings, and community content such as chess streamers from YouTube and Twitch.

---

## Built With

* Kotlin
* Android SDK
* Jetpack Compose
* Retrofit (API consuming)
* Dagger Hilt
* Kotlin Coroutines
* Kotlinx Serialization
* Coil
* Navigation Compose

---

## Features

* 🔍 Search chess players by Chess.com username
* 🏆 Top players ranking by highest ELO on Chess.com
* 👤 Player profile with username, profile picture, and ELO ratings (Blitz, Rapid, Bullet, Puzzles)
* 📺 Chess streamers list with social platforms (YouTube / Twitch) and live status
